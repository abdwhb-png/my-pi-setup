# Pi setup release lifecycle qualification

The implementation at `91025c03b29ee49318c249c5c04a1a819f851327` was validated and promoted from `develop` to `main`. This report records qualification of an unpublished private draft, not a production publication.

## Implemented contract

The operator reads code from an approved main snapshot independently of development edits and captures the personal profile separately. Pi and Zerobox artifacts must match the selected source pins. The private workflow admits a draft by its source, canonical code, runtime identities, asset IDs and SHA-256 fingerprints. Complete installation and profile qualification precede finalization of that same draft. Client downloads retain their published-release and asset attestation checks.

The repository procedure is maintained in the [release skill](../../.agents/skills/pi-setup-release/SKILL.md). `AGENTS.md` contains only the short branch rule and its link. No new development branch, installer, release framework, dependency or package-manager change was introduced.

Its failure is distinct from the passing repository Bun lint and public/private qualification runs; this report does not claim every GitHub workflow is green.
