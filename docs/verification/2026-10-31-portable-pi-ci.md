## Inputs and scope

The dedicated branch is `codex/portable-setup-ci-20261031`, based on the already published `6a0255122dfd3f9d9969f70a3b9392c19ad5c938`. The candidate includes the portable setup implementation and its required sandbox development configuration code. Both jobs reuse the qualified Zerobox artifact from [native run 40901222245](https://github.com/abdwhb-png/my-pi-setup/actions/runs/40901222245). The artifact ZIP digest is `85d20e2deb47781d36edb79851adfa764844f178630db2a90c21fadbb0747898`; the nested runtime archive checksum and the runtime manifest/component hashes are checked before use. The Pi core archives come from the existing committed `pi-core-1.1.0` fixture, verified through the real importer.

The host toolchain uses Node 24.18.0 and Bun 1.3.14. Socket Firewall protects supported package installations after its own bootstrap. Host packages and kernel settings are prepared only on disposable CI runners; the production setup operator still never installs host tools or changes kernel policy.

The synthetic profile uses Hermes 0.9.10, the existing permission-system qualification pin 33.0.0, the footer fork at `98da1a46df80d88ad9842c967676d80a99e275d9` already installed in the source setup, and the bundled local tool-groups package. It contains no personal profile, provider credentials or private memories. Git sources remain commit-pinned and dirty tracked files are still refused.

## Required scenarios

The shared program imports the real Pi runtime, installs packages through the daily CLI, runs the operator and launcher regression suites, packages and extracts a synthetic profile, and installs it into a separate empty home. It then checks runtime coherence, invokes the daily launcher, runs `bash` and `safe_bash` through the installed native sandbox, exports and imports global memory with a rebuilt SQLite search index, performs a real update and idempotent repeat, rolls back, verifies preserved local sessions and memory, and confirms that a managed local edit blocks an update.

No setup transaction substitutes a provisioning callback in this qualification path. The separate fast regression tests retain their documented fixtures. The runtime source and destination are separate directories; the target has no Git checkout and no copied `node_modules` tree.

## Boundaries

The destination HOME is the empty synthetic `/home/pi-ci`. The current Zerobox lease layout requires a worst-case AF_UNIX pathname shorter than 108 UTF-8 bytes; this HOME produces 106 bytes. With this layout, HOME itself may occupy at most 12 UTF-8 bytes. Longer homes remain unsupported by the bundled sandbox; relocating only the setup root does not change that limit.

The global local typecheck still reports four pre-existing errors outside the portability files, listed in the [implementation verification](2026-10-31-portable-pi-setup.md). These jobs qualify the explicit portability contract, not a clean global typecheck or the complete repository test suite.

This qualifies the portable installation mechanism with a synthetic profile and real public package sources. It does not qualify the complete personal profile, private GitHub release publication/download, model/provider connectivity, power-loss durability, or an offline installation. No distribution release is published. GitHub Actions evidence and the reused native artifact have retention limits; refresh the pinned runtime input after its artifact expires.
