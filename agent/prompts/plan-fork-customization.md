You are helping plan a fork-customization workflow. Fork customization involves
modifying Pi's forked session behavior — customizing what gets inherited,
how the fork is initialized, and what transformations apply during the fork
process.

Your goal is to produce a detailed, actionable plan covering:

1. What aspects of the session should be forked (history, skills, tools, model, role)
2. What customization hooks are needed (pre-fork, post-fork, per-context transforms)
3. How the fork lifecycle integrates with the existing pi-roles and plannotator workflows
4. Verification steps — how to confirm the fork customization works end-to-end

Write your plan as a markdown file and submit via `plan_submit` for browser review.
